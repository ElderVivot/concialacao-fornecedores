# Conciliação de Fornecedores

## Atualmente Tem Integração pra Domínio, e pra funcionar tem que fazer o seguinte processo:

1- Acessar a Domínio, gerar o razão da conta de fornecedores
2- Salvar como planilha com cabeçalho
3- Neste projeto criar a pasta razao_dominio e razao_pra_conciliacao
4- Jogar o arquivo salvo da Domínio na pasta razao_dominio
5- Executar python src/main.py e olhar o que gerou na pasta razao_pra_conciliacao
OBS.: Na planilha configuracoes.xlsx dá pra parametrizar os históricos das contas
