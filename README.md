# Conciliação de Fornecedores

### Atualmente Tem Integração com a Domínio, e pra funcionar tem que fazer o seguinte processo:

- Acessar a Domínio, gerar o razão da conta de fornecedores
- Salvar como planilha com cabeçalho
- Neste projeto criar a pasta "razao_dominio" e "razao_pra_conciliacao"
- Jogar o arquivo salvo da Domínio na pasta "razao_dominio"
- Executar `python src/main.py` e olhar o que gerou na pasta "razao_pra_conciliacao"
- OBS.: Na planilha "configuracoes.xlsx" dá pra parametrizar os históricos das contas
